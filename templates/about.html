Platform Overview

The Money Laundering Detection & Risk Intelligence Platform is a comprehensive, production-quality AI-powered Anti-Money Laundering (AML) detection web application built with Python Flask. This platform provides professional financial intelligence capabilities similar to banking AML systems.

The system automatically detects which Kaggle dataset has been uploaded and uses the appropriate trained models and preprocessing pipelines for accurate fraud detection.

Supported Datasets

Dataset 1: Daily Transactions Dataset

Source: Kaggle (prasad22)

Contains daily household transactions with features like payment mode, category, subcategory, amount, and income/expense indicators.

Date Mode Category Subcategory Amount Income/Expense

Dataset 2: Bank Transaction Dataset for Fraud Detection

Source: Kaggle (valakhorasani)

Contains bank transaction data with behavioral features, customer attributes, and fraud indicators for comprehensive fraud detection.

TransactionID AccountID TransactionAmount TransactionType Location DeviceID MerchantID

Machine Learning Models

Random Forest

Ensemble learning method using multiple decision trees for robust predictions.

Support Vector Machine (SVM)

Powerful classification algorithm with kernel methods for complex decision boundaries.

XGBoost

Gradient boosting framework optimized for performance and accuracy.

Key Features

Auto Dataset Detection

Automatically identifies which dataset has been uploaded and uses the appropriate models.

Spider Chart Analysis

Interactive 14-axis risk visualization for detailed transaction analysis.

Network Analysis

Interactive transaction network graphs with D3.js visualization.

SHAP Explainability

Model explainability with force plots, waterfall plots, and feature importance.

Report Generation

Export reports in CSV, Excel, and PDF formats with visualizations.

Advanced Search

Full-text search across all transaction fields with filters.
